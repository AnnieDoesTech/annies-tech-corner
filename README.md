# annies-tech-corner

As an avid user of discord, my goal here is to have a very interactive server where I showcase different ways you can mess with the platform. Utilizing an onboarding feature so that users won't be bombarded with information they don't want or need. Maybe a text channel where the user is able to go on a roleplay adventure with a bot as the guide. A channel that runs trivia or different games, with a leaderboard. Adding custom emojis and soundboard. Maybe a simple "Discord How-To" landing spot. It's limitless if you've got the creativity and know-how for it.
